<decisions>
- Chose 5-skill pipeline over monolithic command — hard boundaries prevent hallucination and enforce discipline
- Skills before Experience in section order — 2025-2026 ATS consensus, keywords scan first
- Removed MCP server — Claude Code reads PDFs and analyzes text natively, Python middleman added nothing
- Removed agents — resume-writer and ats-analyzer were less thorough versions of /polish and /review
- PDF + DOCX dual export — PDF for human reading, DOCX for ATS submission (more reliably parsed)
- .docx is more ATS-reliable than PDF — don't reverse this decision
- Section order is a default, not dogma — format skill has explicit exceptions for new grads, academics, designers
</decisions>
